# daily_stock_analysis：用大模型每天分析自选股，推送到 Telegram、企业微信，能直接跑在 GitHub Actions 上

> 仅供学习研究，不构成投资建议。

**一句话结论**：这是本周 GitHub Trending 上的 A 股相关项目，开源（MIT），7.2 万星。它每天抓自选股的行情、新闻和资金数据，交给大模型写一份“决策仪表盘”，再推送到 Telegram、企业微信、飞书或邮箱。想每天收一份自选股复盘、又不想自己写爬虫，可以拿来用；但报告里的评分和买卖点位是大模型写的，不是回测验证过的信号。

## 要点

- **做什么**：对自选股逐只生成报告，包括核心结论、评分、趋势、买卖点位、风险提示和利好因素；另有大盘复盘（指数、涨跌家数、涨停跌停数、领涨领跌板块）。覆盖 A 股、港股、美股、日股、韩股、台股和 ETF。
- **不用服务器也能跑**：Fork 仓库，在 Secrets 里填一个模型 API Key、一个推送渠道和自选股代码（`STOCK_LIST`），启用 Actions 即可。默认每个工作日北京时间 18:00 运行，A 股、港股、美股的节假日默认跳过。也可以本地或 Docker 部署，`python main.py --schedule` 定时跑，`--webui` 开网页工作台。
- **数据源**：默认用 AkShare、Baostock、YFinance 这些免费源，零配置能跑；项目自己说明免费源受限流和接口变动影响，稳定性不保证，长期定时或批量分析建议配 Tushare 这类要 token 的源。新闻搜索支持 Tavily、Brave、博查等，也支持自建 SearXNG 兜底。
- **Agent 问股**：网页 `/chat` 里可以多轮追问，内置均线、缠论、波浪、趋势、热点、事件驱动等 15 种策略，能调行情、K 线、技术指标和新闻。
- **近两个版本值得看的**：v3.33.0（10 月 15 日）加了一个不用大模型的规则化 ETF 双动量轮动，带扣除成本的回测、年度对比和参数平原检验（看参数稍微变动后结果稳不稳）；v3.34.0（11 月 9 日）更新了各家默认模型，新建文本渠道优先选 MiniMax M3.1 Flash，并修了 Telegram 消息长度按 UTF-16 计算不对导致的超长问题。

## 适合谁

- 有固定自选股、想每天收盘后自动收一份复盘推送的人。
- 已经有 Telegram 机器人、想参考别人怎么组织“行情 + 新闻 + 大模型”报告格式的人。
- 在做自己的选股或回测工具的人：ETF 双动量模块里的扣成本回测和参数平原检验，思路可以借鉴。

## 注意事项

- **报告不等于信号**：评分、买卖点位、利好利空都是大模型根据抓到的数据和新闻写的，没有经过回测验证；新闻搜索没配好时，舆情部分质量会明显下降。拿来当信息汇总可以，别直接照着下单。
- **README 里推广链接很多**：赞助区和配置表里有模型中转、行情源的注册返利链接。本条不转载，需要哪个服务自己去官方站注册。
- **密钥只放 Secrets**：API Key、机器人 token 和自选股都按项目说明放在仓库 Secrets 里，不要写进代码或配置文件后提交。
- **免费数据源会抽风**：上游接口一改或被限流，当天的报告可能缺数据，要留意推送里的报错。
- 本条只整理了项目 README 和 GitHub 发布说明，没有实际部署测试。
