# daily-digest

每日整理：免费云资源、AI 编程代理、A 股量化的社区精华摘要。

Daily curated digest of community posts on free cloud resources, AI coding agents and China A-share quant research. Summaries are written in Chinese.

每天从 linux.do、V2EX、Hacker News、GitHub Trending、知乎、少数派、Reddit 等社区挑出 1 到 3 条有干货的帖子或文章，用自己的话写成摘要，并附上原帖链接。

## 收录原则

- **自己的话摘要**：每条都是重新组织的中文摘要，不整段照搬原文。
- **附原链接**：每条都写明来源社区、原帖链接和日期，原帖版权归原作者。
- **只搬公开内容**：需要登录才能看的内容不往外搬。
- **不放推广**：不放推广链接、邀请码、返利链接和任何个人信息。
- **投资内容仅供学习研究**：涉及投资的条目都注明“仅供学习研究，不构成投资建议”。
- **宁缺毋滥**：没有好素材的日子宁可不加，或者回头更新已收条目（比如某个免费资源已经失效）。

详细格式见 [CONTRIBUTING.md](CONTRIBUTING.md)。
