# Google Cloud 免费试用改规则：11 月 16 日起新开的账号，300 美元赠金不能再花在 Gemini 上

**一句话结论**：Google Cloud 官方文档（2026-11-13 更新）写明，**2026 年 11 月 16 日及以后**注册免费试用或升级成付费账户的，300 美元赠金不能再用来付 Gemini 平台（原 Vertex AI）的费用；AI Studio 里的 Gemini API 和第三方模型 API 本来就不能用赠金付。想靠 GCP 赠金白嫖大模型的路基本堵上了，但赠金跑虚拟机、数据库这些照旧，永久免费的 e2-micro 也没变。

## 要点

- **赠金不能付的三类**：
  - Gemini 平台（原 Vertex AI）的服务：11 月 16 日及以后注册试用或升级付费的账号适用。
  - AI Studio 里的 Gemini API：官方建议改用 Gemini API 自己的免费档，或者预付费套餐。
  - 以托管 API 形式提供的第三方生成式 AI 模型（Model-as-a-Service）。
- **试用本身没变**：新用户 300 美元赠金，90 天内有效，用完或到期就结束；注册要绑卡或其他付款方式，银行可能看到一笔 0 到 1 美元的临时预授权，不是真扣钱。
- **试用期间不能做的事**：给虚拟机加 GPU、用 Marketplace、申请提额、开 Windows Server 虚拟机、建 VMware Engine 资源；挖矿禁止。
- **试用结束不升级会怎样**：资源全部停掉，进入 30 天宽限期；宽限期内升级成付费账户可能还能找回，过了就永久删除。
- **永久免费档（Free Tier）还在**：每月 1 台 e2-micro（只限美国 us-west1、us-central1、us-east1 三个区）、30 GB 标准硬盘、每月 1 GB 从北美出站流量（不含到中国和澳大利亚）；Cloud Run 每月 200 万次请求等。免费档没有截止日期，但 Google 保留提前 30 天通知后修改的权利。

## 适合谁

- 打算新开 GCP 账号、想用赠金跑 Gemini 或 Vertex AI 的人：今天起这条路走不通了，直接用 AI Studio 的 Gemini API 免费档更现实。
- 想要一台永久免费小机器的人：e2-micro 还能用，但只有 1 GB 内存、每月出站流量只有 1 GB，适合监控、跑小脚本这类轻活。

## 注意事项

- **看清楚自己账号的注册或升级日期**：文档写的是“在 11 月 16 日或之后注册试用或升级付费”，之前已经在试用期的账号，按字面不受这条影响，但最好在账单里确认赠金到底抵扣了哪些项目。
- **升级成付费账户后要防超额**：升级后剩余赠金还能用到原来 90 天期满，超出赠金、超出免费档或不在试用范围内的用量会直接从卡里扣。先设预算提醒再开资源。
- **e2-micro 的免费按小时算**：每月所有 e2-micro 合计用满当月总小时数就开始收费，开两台等于一半时间要付钱；GPU、TPU 永远收费。
- 没在 Hacker News、V2EX 上找到对这条改动的讨论，本条只依据 Google Cloud 官方文档整理。
